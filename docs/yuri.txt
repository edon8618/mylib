yuri: 有理数
対象: yuri.hpp / C++20

【概要】
分母を正、分子分母を互いに素に保つ有理数。

【テンプレート引数】
なし。保存は ll、コンストラクタ引数は __int128_t。

【公開API】
yuri(si=0,bo=1)。公開 bunsi/bunbo。四則演算 + - * /、比較6種。
abs(yuri)、cout への出力（整数なら整数、それ以外は分子/分母）。

【計算量】
構築と四則演算は約分の互除法 O(log B)、比較 O(1)。空間 O(1)。
B は約分前の数値の大きさ。128bit演算を定数時間とする。

【注意点】
bo!=0、0による除算不可。約分後の分子・分母が ll に収まること。
加減算の中間値も128bitに収める。範囲外キャストの検査はない。
abs は LLONG_MIN の分子を避ける（符号反転が ll のまま行われる）。

【内部実装用】
約分処理はコンストラクタ内。bunsi/bunbo を直接変更すると不変条件が崩れる。

【依存関係】
tmp.cpp の標準ヘッダー・using・型／マクロ。追加の外部ライブラリなし。

【使用例（C++20）】
--- C++20 ここから ---
#include "mylib/yuri.hpp"
void solve(){
    yuri a(1,2), b(1,3);
    assert(a + b == yuri(5,6));
    cout << a + b << '\n'; // 5/6
}
