KMP: prefix function
対象: KMP.hpp / C++20

【概要】
文字列の各位置までの、真の接頭辞かつ接尾辞の最大長を返す。

【テンプレート引数】
なし。引数は string。

【公開API】
KMP(const string& s)->vector<int>。pi[i] は s[0..i] の最長border長。
パターンの検索位置を直接返す関数ではない。

【計算量】
時間 O(|s|)、返却配列 O(|s|)、その他 O(1)。

【注意点】
空文字列なら空配列。照合に区切り文字を使う場合は入力に含まれない文字を選ぶ。

【内部実装用】
外部向け補助関数なし。関数内の j は失敗辺をたどる長さ。

【依存関係】
tmp.cpp の標準ヘッダー・using・型／マクロ。追加の外部ライブラリなし。

【使用例（C++20）】

#include "mylib/KMP.hpp"

    auto pi = KMP("ababa");
    assert((pi == vi{0, 0, 1, 2, 3}));

}
