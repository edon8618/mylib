mylib 使い方一覧

対象: 更新版mylib + 追加されたTree.hpp。計49ヘッダー。
各 .hpp に対応する同じ相対パスの .txt を docs/ に収録。
例: geometoric/geo_int.hpp → docs/geometoric/geo_int.txt
使用例は同梱されていた tmp.cpp の ll/rep/mint/using 等を使用するC++20コード。
入力のある例は入出力仕様を本文に記載。その他は小さな固定データで動作を示す。

通常のincludeパスの例:
  ~/lib/mylib/AVLtree.hpp
  ~/lib/ac-library-master/atcoder/all

g++ -std=c++20 -O2 -I "$HOME/lib" -I "$HOME/lib/ac-library-master" a.cpp -o a.out
oj-bundle a.cpp -I "$HOME/lib" -I "$HOME/lib/ac-library-master" > a_submit.cpp
g++ -std=c++20 -O2 a_submit.cpp -o a.out

幾何ヘッダー2本のみ、ヘッダー内の ll/ld の型別名とtmp.cppのマクロが
衝突するため、#define ll / #define ld より前のinclude群で読み込む。
他の例の演算関数はグローバル定義。同時利用で op/e/S/F 等が衝突する場合は
関数名・型名を用途別に変える。

計算量は原則として利用者の演算・比較・値コピーが O(1) の場合。
未確認の厳密な償却・最悪計算量を推定して断定せず、不明と明記した。
構造体が言語上 public にしている内部関数も、通常の利用APIと区別して記載。

ライブラリのソース変更なし。このZIPは説明ファイルのみを含む。
tests/bench_reference の2本は比較実験用で、通常はルートの本体を利用する。

確認結果:
・49本全ての使用例を、実際のtmp.cppに組み込んでC++20でコンパイル・実行。
・49本全てでoj-bundle展開後にもコンパイル・実行。
・小さな固定例のassert、およびHLDの入力例の出力を確認。
・元ソースとtmp.cppの内容はSHA-256で変更がないことを確認。
これは掲載例の確認であり、全てのAPI・入力の網羅的な検証ではない。
