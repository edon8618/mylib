Angle: 偏角順ソート
対象: angle_sort.hpp / C++20

【概要】
非零ベクトルを正のx軸から反時計回りに並べる。

【テンプレート引数】
なし。座標 x,y は ll。

【公開API】
Angle(ll x=0,ll y=0)、公開 x,y。operator<: 偏角順。
operator==: 同じ向きか（長さや座標の一致ではない）。

【計算量】
比較 O(1)、N個のsort O(N log N)、比較器の追加領域 O(1)。

【注意点】
(0,0) は必ず除く。外積比較は ll の積なのでオーバーフローに注意。
同じ向きの長さ順までは定めない。

【内部実装用】
private location(): 上半平面・下半平面の分類。

【依存関係】
tmp.cpp の標準ヘッダー・using・型／マクロ。追加の外部ライブラリなし。

【使用例（C++20）】
--- C++20 ここから ---
#include "mylib/angle_sort.hpp"
void solve(){
    vector<Angle> a = {{0,-1}, {-1,0}, {0,1}, {1,0}};
    sort(all(a));
    assert(a[0].x == 1 && a[1].y == 1);
    cout << a[2].x << '\n'; // -1
}
