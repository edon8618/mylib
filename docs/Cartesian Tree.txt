CartesianTree: 配列のCartesian木
対象: Cartesian Tree.hpp / C++20

【概要】
中間順が元の添字順、親の値が比較器で優先される二分木を作る。

【テンプレート引数】
CartesianTree<T>。T は配列要素型。
コンストラクタ自体にも Compare=less<T> の型引数があり、比較器を渡せる。
comp(a,b)=true なら a が b より親になる。既定は最小値が根。

【公開API】
CartesianTree(const vector<T>& a,Compare comp=Compare())。
公開 root と P/L/R（各頂点の親／左右の子、なければ-1）。

【計算量】
構築 O(N)、空間 O(N)。比較・コピー O(1) を仮定。

【注意点】
同値ではpopしないので同じ最小値なら左側が優先。空配列でも root=0 となるが
有効な頂点はないため参照しない。木への更新機能なし。

【内部実装用】
コンストラクタ内の単調スタックは内部用。

【依存関係】
tmp.cpp の標準ヘッダー・using・型／マクロ。追加の外部ライブラリなし。

【使用例（C++20）】

    CartesianTree<ll> ct(vl{3,1,2});
    assert(ct.root == 1 && ct.L[1] == 0 && ct.R[1] == 2);
    cout << ct.root << '\n';
}
