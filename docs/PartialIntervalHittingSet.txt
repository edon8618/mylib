PartialIntervalHittingSet: 直線上の重み付き Partial Interval Hitting Set
対象: PartialIntervalHittingSet.hpp / C++20以降

【概要】
閉区間 [l_i, r_i] に非負整数重み w_i が付いている。
直線上に高々 k 個の点を選び、「1点以上を含む」区間の重みの総和を最大化する。
復元あり/なしを指定可能。重複区間や点区間 [x,x] に対応。
全区間を刺すための最小点数も右端貪欲法で求められる（フローを使わない）。

【公開API】
template<class Coord = long long> struct PartialIntervalHittingSet
  void add(Coord l, Coord r, long long w = 1);
    閉区間 [l,r] を追加。l<=r, w>=0 が必要。
    w=0 は solve() では無視するが、min_points_to_cover_all() では被覆対象。
  int size() const;
    追加した区間の個数（w=0 もカウント）。
  Result solve(int k, bool restore = false) const;
    高々 k 点を置くときの最大得点。k>=0。
    return.value  : long long 最大被覆重み
    return.points : vector<Coord> 最適な設置座標（restore=true 時のみ）
    restore=false では points は常に空。
    restore=true でも、必ずしも k 点ちょうどを返すわけではない。
    重複座標はなく、昇順で返る。復元される解は一意とは限らない。
  Result min_points_to_cover_all(bool restore = false) const;
    追加した全区間を刺すための最小点数を求める。重みは考慮せず w=0 も対象。
    return.value  : long long 必要な最小点数（solve() の意味とは異なる）
    return.points : vector<Coord> 最小点集合（restore=true の場合のみ）
    右端の昇順に区間を処理して、直前の点で刺せなければ右端に点を置く。
    フローは一切使わない。O(n log n) 時間、O(n) 空間。
  solve() と min_points_to_cover_all() はデータを破壊せず、複数回呼べる。

【依存関係】
- 自分の mylib/Mincostflow_with_Negative.hpp
  (型名 MinCostFlowWithNegative<Cap,Cost>)
- AtCoder Library: <atcoder/mincostflow>
- C++ 標準ライブラリ (このヘッダで読み込む)
- 使用する MCF の仕様: add_edge(from,to,cap,cost), flow(s,t,limit), edges()。
  MCF 本体はここには複製しない。

【使用例】
#include <bits/stdc++.h>
#include <atcoder/all>
using namespace std;
#include "mylib/PartialIntervalHittingSet.hpp"

int main() {
    PartialIntervalHittingSet<long long> solver;
    solver.add(1, 3);
    solver.add(2, 5);
    solver.add(4, 6, 2); // 重み 2

    auto minimum = solver.min_points_to_cover_all(true);
    cout << minimum.value << '\n'; // 2
    for (auto p : minimum.points) cout << p << ' ';
    cout << '\n';

    auto a = solver.solve(1);
    cout << a.value << '\n'; // 3

    auto b = solver.solve(2, true);
    cout << b.value << '\n'; // 4
    for (auto p : b.points) cout << p << ' ';
    cout << '\n';
}

【最小点数版】
min_points_to_cover_all() は区間を右端の昇順にソートし、現在の点で刺せない
区間に遭遇したらその区間の右端を採用する。各点の復元もそのまま可能。
MCFやSPFAは呼ばない。重み w=0 の区間も対象。

【内部アルゴリズム】
重み合計 W を計算し、候補座標として全区間の右端を座標圧縮する。
頂点 0..m、始点 s、終点 t を用意して以下を張る。

辺             容量  費用
s -> t         W+2    0     ダミー（余った流量）
s -> 0         W+1    k     1本あたり k のコスト
j -> j+1       W+1    0     隣接頂点
L_i -> R_i     w_i   -1     区間辺。L=lower_bound(xs,l), R=upper_bound(xs,r)
m -> t         W+1    0

s から t に W+1 流し、答え = W + 最小費用。
これは双対のフローであり、流量は設置点の個数ではない。
選んだ区間辺の流量の総和を c、ダミーでないパス流量を q とすると費用 kq-c。
区間の連続1性・整数性によって双対上界が厳密になる。

restore=true のときは、最終フローの edges() から残余グラフを構築。
残余辺 (u,v,c) に対して d[v]<=d[u]+c となる整数ポテンシャル d を
SPFAで求める。各候補 xs[j] を d[j]>d[j+1] のとき採用。
復元は MCF 本体を変更する必要がない。

【計算量】
区間数を n、重み総和を W とする。頂点・辺はともに O(n)。
前処理は O(n log n)。元の MCF の整数流量上界で評価すると、
初期 SPFA が最悪 O(n^2)、増加路計算が概ね O(W*n*log n) 上界。
実際の増加路回数は容量をまとめて流すので W より少ないことがある。
復元には残余グラフ上の SPFA を1回追加（最悪 O(n^2)）。
空間 O(n)。
すべての区間を k 点以内で刺せる場合は貪欲法で O(n log n) 終了。

【注意事項】
- 重み w_i は非負整数。負重みは非対応。
- k は「高々 k 個」。区間は閉区間で、点の座標は右端から選べる。
- W は 64-bit 符号付き整数と、MCF のコスト演算で安全な範囲に収める。
  実装では W<=LLONG_MAX/4 を assert する。
- 座標型 Coord は比較・ソートが可能であること。整数型を推奨。
- MCF の restore=true は通常よりコストがかかる。
- Github の既存 MCF に変更は加えていない。
