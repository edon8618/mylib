extend_gcd: 拡張ユークリッド互除法
対象: extend_gcd.hpp / C++20

【概要】
a*x+b*y=d を満たす係数を求める。

【テンプレート引数】
extend_gcd<T>。T は符号付き整数など / % 四則演算ができる型。
a,b,x,y は同じ型で渡す。__int128 も使用可能。

【公開API】
T extend_gcd(T a,T b,T& x,T& y)。返り値 d は再帰終端の値。

【計算量】
非負整数では O(log(min(a,b)+1)) 回の除算（0の場合は定数回）。再帰領域も同程度。

【注意点】
a,b>=0 なら非負のgcd。負数を渡した場合、gcdの符号は正規化されない。
係数計算の中間値が T に収まること。a=b=0 では d=0,x=1,y=0。

【内部実装用】
同じ関数の再帰のみ。

【依存関係】
tmp.cpp の標準ヘッダー・using・型／マクロ。追加の外部ライブラリなし。

【使用例（C++20）】
--- C++20 ここから ---
#include "mylib/extend_gcd.hpp"
void solve(){
    ll x, y;
    ll g = extend_gcd(30LL, 18LL, x, y);
    assert(g == 6 && 30*x + 18*y == g);
    cout << g << '\n';
}
