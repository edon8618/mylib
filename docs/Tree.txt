Tree: 重み付き木・LCA・直径・重心分解
対象: Tree.hpp / C++20

【概要】
静的な無向木で直径の経路、LCA、重み和／XOR距離、重心木を構築する。

【テンプレート引数】
Tree<T>。T は辺重みと和／XOR距離の型。
build_lca は内部で ^ を使うので、通常 T=ll などの整数型にする。

【公開API】
Tree(int n)。add_edge(int u,int v,T w): 重み付き無向辺。
add_edge(u,v): 重み1。公開 graph[v] は Edge{to,weight} の配列。
get_diameter_and_path()->pair<T,vector<int>>: {直径長,端点から端点への頂点列}。
build_lca(int root=0): LCA・和距離・XOR距離を前計算。
get_lca(u,v)->int / get_dist(u,v)->T / get_xor_dist(u,v)->T。
decompose(): 重心木を作る。結果 centroid_parent[v]、重心木の根は親=-1。

【計算量】
構築 O(N)、辺追加償却 O(1)。直径 O(N)、LCA前計算 O(N log N)、
LCA/距離クエリ O(1)。重心分解 O(N log N)。空間はLCA O(N log N)、他 O(N)。

【注意点】
直径を二度の最遠探索で求めるので、重みは非負を前提にする。
get_lca/get_dist/get_xor_dist の前に build_lca。build_lca は tour.clear() を
しないので1インスタンス1回だけ。更新後に再buildする用途は避ける。
N=0で許されるのは直径API（{0,{}}）だけ。decompose/build_lca はN>=1。
全DFSは再帰で、パス状の木ではO(N)の呼び出し深さ。
decompose 後は cd_removed が全true。削除状態を元の木に反映する操作ではない。

【内部実装用】
dfs/dfs_euler/cd_calc_size/cd_find_centroid/build_centroid_tree は内部用
（言語上public）。tour/first_visit/depth/dist_from_root/xor_from_root/st、
cd_removed/cd_sz は作業状態。centroid_parent は参照用の出力。

【依存関係】
ヘッダーは algorithm/utility/vector を読み込む。例は tmp.cpp の ll/cout。

【使用例（C++20）】
--- C++20 ここから ---
#include "mylib/Tree.hpp"
void solve(){
    Tree<ll> tree(4);
    tree.add_edge(0,1,2); tree.add_edge(1,2,3); tree.add_edge(1,3,4);
    auto [diameter,path] = tree.get_diameter_and_path();
    tree.build_lca();
    assert(diameter == 7 && tree.get_lca(2,3) == 1);
    assert(tree.get_dist(2,3) == 7 && tree.get_xor_dist(2,3) == (3^4));
    tree.decompose();
    assert(tree.centroid_parent[1] == -1);
    cout << diameter << '\n';
}
