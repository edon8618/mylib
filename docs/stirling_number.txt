stirling_number

【概要】
第1種・第2種スターリング数。n固定の行、k固定の列を生成。
第1種は既定で符号なし（n要素の置換でサイクル数k）。
第2種はn要素をk個の非空集合に分割する方法数。

【公開API】
fps stirling1_n_fix(int n, bool signed_res=false)
fps stirling2_n_fix(int n)
  k=0,...,n の順。長さn+1。
fps stirling1_k_fix(int k, int max_n, bool signed_res=false)
fps stirling2_k_fix(int k, int max_n)
  n=0,...,max_n の順。長さmax_n+1。
第1種のsigned_res=trueは各項に(-1)^(n-k)を掛ける。
S(0,0)=[0,0]=1。k>max_nは零列。k=0は {1,0,...}。

【計算量】
行: O(n log(n+2))、列: O(N log(N+2)+log(k+1))、N=max_n+1。
補助空間O(n)またはO(N)。法998244353の演算は固定コストとしている。

【注意点・内部実装】
n,k,max_nは非負。n,max_nはmod未満。不正値はinvalid_argument。
実用上はqandoriの変換長制約も必要（出力長2^22以下を目安）。
このヘッダーには fps/taylor_shift.hpp の事前includeも必要。
（第1種の行の実装が参照するため。他の関数のみ使う場合も必要。）
内部専用の公開関数はない。powはqandoriの「元の長さで打切り」を利用。

【依存関係・配置】
qandori/cp-library の fps/fps.hpp を先に include する。
係数型は qandori の mint (mod 998244353)、多項式型は fps。
tmp.cppにACL版mintの別名定義があれば、この構成では除く（名前衝突）。
このヘッダーには qandori の実装・include は含めない。
例では qandori のルートを -I に渡し、自作ヘッダーも -I に渡す。
C++20: g++ -std=c++20 -O2 -I/path/to/cp-library -I/path/to/addons main.cpp
bundle: oj-bundle -I/path/to/cp-library -I/path/to/addons main.cpp > submit.cpp
テンプレート引数はない。ACLのmintや別modのFPSはそのまま渡せない。
例の ll・rep・using は tmp.cpp に既にあれば再定義不要。

【使用例（C++20）】
#include <bits/stdc++.h>
#include "fps/taylor_shift.hpp"
#include "stirling_number.hpp"
using namespace std;
using ll = long long;
#define rep(i,n) for(ll i=0;i<(ll)(n);++i)

void solve(){
    auto a = stirling2_n_fix(4);
    rep(i,a.size()) cout << a[i] << (i+1==(ll)a.size()?'\n':' ');
    // 0 1 7 6 1
    auto b = stirling1_k_fix(2,4);
    rep(i,b.size()) cout << b[i] << (i+1==(ll)b.size()?'\n':' ');
    // 0 0 1 3 11
}
int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    solve();
}
